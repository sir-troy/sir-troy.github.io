Analytics engineering · BPO

Data Analytics Integration Platform

A company-wide analytics platform that brings every CRM and business tool into one modeled BigQuery warehouse. I'm one of the three engineers who maintain the entire infrastructure.

  • Ingests from Zendesk, HubSpot, Zoho, DataDepot, respond.io, Google Drive, Google Sheets and more.
  • Connects through Fivetran, Airbyte and inbox-to-Cloud-Storage loads, plus Cloud Functions that call a source API directly when no connector exists.
  • Models data in BigQuery across source, staging, mart and view layers.
  • Jobs run daily, hourly, every 4 hours or twice a day, each with its own config, assertions and rules.
  • Serves Looker Studio dashboards, Google Sheets, Google Drive exports and scheduled report emails.

AML compliance · Fintech

Suspicious Transaction Reporting Pipeline

An end-to-end pipeline that turns compliance team submissions into regulatory suspicious transaction reports, with secure delivery and a built-in recovery path.

  • Validates every incoming file and routes it automatically to a processed or failed path.
  • Generates customer, transaction and report-detail files, delivered over SFTP with TLS encryption.
  • Failed files raise a webhook alert and follow a decrypt, fix and reprocess loop.

Compliance · Data integration

Unified Sanctions Watchlist Platform

One central, deduplicated watchlist built from many sanctions and blacklist sources, distributed securely to partner screening platforms.

  • Ingests from spreadsheets, a risk-data API, Python web scrapers, Airflow DAGs and file drops.
  • Posts ingestion stats to Google Chat, with active and inactive counts per source.
